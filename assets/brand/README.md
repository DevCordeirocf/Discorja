# Logo do Discorja

A imagem enviada pelo autor é a logo oficial de referência. As duas variações são estudos de cor para revisão no Figma.

| Arquivo                    | Uso                                                         |
| -------------------------- | ----------------------------------------------------------- |
| `discorja-original.png`    | Original fornecido pelo autor, preservado sem alterações.   |
| `discorja-lilas-menta.png` | Proposta com chifres lilás e menta e fundo azul.            |
| `discorja-grafite.png`     | Proposta com chifres lilás e menta e fundo grafite/violeta. |

As cores de referência da proposta são lilás **#B8A0FF** e menta **#A6DFC8**, já presentes na interface. Os arquivos têm gradientes; seus pixels não são cores uniformes.

[Comparar no Figma](https://www.figma.com/design/YbeCeb5y0429UnVs7tqdCN?node-id=13-48)

O original foi aplicado às sete telas de proposta no Figma. Para comparar outra opção, selecione uma instância de **Logo oficial Discorja** e altere **Paleta** no painel direito. O PNG é uma imagem: os chifres não são formas vetoriais separadas.

As variações foram criadas com a ferramenta integrada de edição de imagem, usando o original como entrada. Podem existir pequenas diferenças de traço. A edição não utilizou os créditos de IA do Figma.

Estes arquivos ainda não substituem os ícones do instalador nem a logo no código do aplicativo. A aplicação ao app fica para a etapa de implementação do visual escolhido.

## Instruções usadas na edição

### Chifres lilás e menta

Use case: precise-object-edit. Input image is the edit target: the supplied official Discorja skull-with-horns app logo. Preserve the skull silhouette, eye sockets, nose, teeth, both horn outlines and placement, all proportions, square framing, rounded square tile geometry, shaded smooth vector-like rendering and overall identity. No text, no watermark, no new objects. This is a color exploration, not a redesign. Preserve the ivory/periwinkle skull shading and dark cutouts. Change ONLY the colored exterior faces of the horns: the viewer-left cyan blue horn becomes soft lavender #B8A0FF, and the viewer-right hot pink horn becomes soft mint #A6DFC8. Keep their subtle gradients and volumes consistent with those target hues. Keep the original intense electric indigo-blue rounded-square tile and the dark outer background unchanged. Return one clean square logo asset.

### Paleta com fundo grafite

Use case: precise-object-edit. Input image is the edit target: the supplied official Discorja skull-with-horns app logo. Preserve the skull silhouette, eye sockets, nose, teeth, both horn outlines and placement, all proportions, square framing, rounded square tile geometry, shaded smooth vector-like rendering and overall identity. No text, no watermark, no new objects. This is a color exploration, not a redesign. Preserve the ivory/periwinkle skull shading and dark cutouts. Color-harmonized alternative for a dark desktop app. The viewer-left cyan blue horn becomes soft lavender #B8A0FF, the viewer-right hot pink horn becomes soft mint #A6DFC8, retaining gentle gradients and volumes. Additionally change the electric blue rounded-square tile to a subtle deep graphite-violet gradient, centered around #22232D with restrained #2C263D shading, and the outer background to near-black #101115. Preserve the skull's pale ivory/periwinkle tone and all shapes; dark cutouts should be deep plum #17151F for contrast. Return one clean square logo asset.
